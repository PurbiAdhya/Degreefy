# Degreefy

Open `index.html` through a web server or GitHub Pages. Opening the file directly with `file://` may prevent browsers from loading the CSV files; the embedded sample data will still work.

The guided workflow asks:

1. Student, faculty, or staff
2. Incoming, transfer, current, or returning student
3. Planned graduation year and term
4. Majors and minors, grouped across academic areas
5. Completed/transferred core courses (skipped for incoming students)
6. Completed/transferred program courses (skipped for incoming students)
7. Plan journey, print checklist, or print plan

The original planner engine remains in place for prerequisites, corequisites, typical offerings, minimum/maximum term credits, automatic population, and distinct-credit checks.
